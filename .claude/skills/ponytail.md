# Ponytail

Жёсткое упрощение решения: оставить минимальный код, который надёжно выполняет требование.

## Процесс

1. Сформулировать обязательное поведение и удалить всё, что не нужно для него.
2. Найти premature abstraction, duplicate source of truth, speculative options и лишние слои.
3. Проверить, можно ли использовать существующий utility, public API или простой data structure.
4. Уменьшить branches, state и configuration, сохранив читаемость и тестируемость.
5. Запустить тесты и отдельно проверить, что упрощение не убрало auth, error handling или edge cases.

## Правила

- Простота не оправдывает уязвимость, потерю данных или нарушение контракта.
- Не менять scope ради эстетической чистки.
- Каждое удаление должно иметь evidence: тест, usage search или измерение.
