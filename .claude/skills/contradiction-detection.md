# Contradiction Detection

Поиск противоречий между задачей, документацией, кодом и тестами.

## Процесс

1. Собрать утверждения из prompt, `README.md`, `docs/`, API-контрактов и текущего кода.
2. Сгруппировать их по поведению, данным, состояниям и срокам.
3. Найти несовместимые значения, приоритеты или обязательства.
4. Определить authoritative source и влияние каждого варианта.
5. Не кодировать спорное поведение до фиксации решения и теста.

## Отчёт

Указывать источники, точную формулировку конфликта, affected paths и предложенный вопрос владельцу требования.
