# Package Research

Проверять пакет и версию перед добавлением зависимости.

## Чеклист

1. **Необходимость**: можно ли решить без новой зависимости? stdlib / уже установленные пакеты?
2. **Поддержка**: последние коммиты, открытые issues, время ответа мейнтейнеров
3. **Безопасность**: известные CVE, аудит через `pip audit` / `npm audit`
4. **Размер**: влияние на bundle (frontend) или image size (backend)
5. **Лицензия**: совместимость с проектом
6. **Версия**: pin в requirements.txt / package.json, не `latest` / `*`
7. **Альтернативы**: 2-3 аналога, сравнение по критериям

## Правила

- Каждая новая зависимость — явное решение с записью в decision log
- Проверять `pip install --dry-run` / `npm install --package-lock-only` перед commit
- Frontend: проверять tree-shaking поддержку
- Backend: проверять совместимость с текущей Django/Python версией
