# Alternative Analysis

Сравнение 2–3 вариантов решения по явным критериям.

## Процесс

1. Описать обязательный результат и ограничения.
2. Сформировать минимум два реалистичных варианта, включая simplest viable option.
3. Оценить correctness, security, complexity, performance, operability и reversibility.
4. Выбрать вариант с лучшим соответствием текущему scope, а не гипотетическому будущему.
5. Зафиксировать отвергнутые альтернативы и последствия в decision log.

## Антипаттерны

- Сравнивать straw-man с заранее выбранным решением.
- Выбирать «самый гибкий» вариант без измеримой потребности.
- Скрывать trade-off вместо фиксации technical debt.
