# Invariant Checking

Выделение свойств системы, которые должны оставаться истинными.

## Процесс

1. Записать preconditions, postconditions и invariants операции.
2. Проверить их на уровне serializer/service и database constraints.
3. Рассмотреть partial failure, retry, duplicate request и concurrent update.
4. Добавить тест на сохранение каждого критического invariant.
5. Проверить, что error path не оставляет незаконное состояние.

## Примеры

- Нельзя сохранить ссылку на несуществующий объект.
- Повторная доставка события не создаёт двойную запись.
- Неавторизованный пользователь не получает чужие данные.
