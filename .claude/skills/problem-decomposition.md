# Problem Decomposition

Разбиение сложной задачи на независимые проверяемые части.

## Процесс

1. Сформулировать конечный результат и критерии готовности.
2. Разделить задачу по слоям: UI → API → service → DB → infrastructure.
3. Выделить независимые work items, зависимости и блокирующие решения.
4. Для каждого item указать входы, выходы, владельца логики и способ проверки.
5. Сначала выполнить критический путь, затем независимые части.

## Проверки

- Каждый пункт имеет однозначный результат.
- Нет скрытой зависимости или общей изменяемой state.
- Границы задачи не смешаны с будущими улучшениями.
