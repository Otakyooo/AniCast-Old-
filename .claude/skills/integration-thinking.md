# Integration Thinking

Проверка работы изменения с реальными соседними модулями и внешними границами.

## Процесс

1. Составить карту интеграций: API, DB, Redis/Celery, browser и Compose.
2. Для каждой границы указать contract, timeout, retry, auth и failure behavior.
3. Проверить порядок запуска и graceful degradation при недоступной зависимости.
4. Выполнить integration/contract test через реальный интерфейс, где это возможно.
5. Проверить observability и rollback для частично успешной операции.

## Правило

Mock не должен скрывать несовместимость протокола, схемы или жизненного цикла зависимости.
