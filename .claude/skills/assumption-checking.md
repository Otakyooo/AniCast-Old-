# Assumption Checking

Поиск и проверка допущений до реализации.

## Процесс

1. Выписать все утверждения, на которых держится решение.
2. Для каждого указать источник, уверенность и последствия ошибки.
3. Проверить допущения по коду, docs, контракту API или воспроизводимому эксперименту.
4. Непроверенные допущения превратить в вопрос, тест или явное ограничение.
5. Повторить проверку после изменения соседнего модуля.

## Антипаттерны

- Предполагать формат API по названию поля.
- Предполагать поведение браузера, БД или очереди без теста.
- Молчаливо принимать fallback за корректный результат.
