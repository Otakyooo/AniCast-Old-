# Anicast: бренд и темы

Актуализировано 09.09.2026 по `Anicast-Brand-Guide-v01.pdf`, страницы 4–8,
и последующим требованиям владельца к темам и фону логотипа.
HEX-таблица PDF имеет приоритет над оттенками растровых макетов. Счётчики,
названия и постеры в макетах демонстрационные: приложение использует API каталога.

## Источники реализации

- `frontend/app/theme.css`: общие семантические роли, тёмная и светлая темы.
- `frontend/app/globals.css`: базовые элементы и каркас; CSS Modules: страницы.
- `frontend/lib/theme.ts`: применение до первого отображения, явный выбор темы,
  сохранение выбора и синхронизация вкладок.
- `frontend/components/theme-switcher.tsx`: доступный native select в меню
  предпочтений (гости) / пользователя (вход выполнен); в самой шапке с 11.09
  только триггер меню.
- `frontend/components/brand-lockup.tsx`: единое написание **Anicast** в обеих темах.

Поверхности разведены по светлоте намеренно: фон страницы темнее карточки,
карточка темнее панели/hover, поэтому блоки читаются без рамок. Карточки
и большинство контейнеров не имеют border — разделение делается фоном,
отступами и типографикой; рамки остаются у интерактивных контролов
(поля, селекты, кнопки-шаги, фокус- и выбранные состояния).

Янтарь — цвет главного действия (заливки CTA «Смотреть»/«Продолжить») и
фокус-кольца. Мелкий текст ссылок и подписей в тёмной теме использует
спокойный кремовый `accent-text`, а не тот же янтарь; hover-состояния карточек
меняют поверхность, а не цвет рамки. В светлой теме мелкий текст — ягодный,
как и раньше.

Ягодный не становится фоном страницы. Белые поверхности остаются белыми.
Disabled-кнопки нейтральные. Прогресс дополняется текстом серии и охристым краем.
Hero остаётся тёмным со светлым текстом; постеры и цвета маскота не инвертируются.
Шапка на 768–1439 px имеет две строки: бренд/поиск/действия и навигация —
четыре прямые ссылки (Главная/Каталог/Расписание/Библиотека), остальное
(Франшизы/Коллекции/Сообщество) — в раскрывающемся «Ещё».

## Поведение и типографика

По требованию владельца от 09.09.2026 доступны только светлая и тёмная темы.
По умолчанию выбрана тёмная; старое значение `system` также означает тёмную.
Явный выбор `light` или `dark` сохраняется под `localStorage["anicast-theme"]`.
Изменения темы ОС не влияют на сайт. При недоступности storage переключение работает в текущей
вкладке. `theme-color` и `color-scheme` следуют фактически выбранной теме.

Manrope Variable с кириллицей распространяется вместе с приложением; fallback —
системный sans-serif. Noto Sans JP остаётся для японских названий. Никаких запросов
к Google Fonts из браузера. Базовый текст 16 px; метаданные 14 px; hero главной
28–38 px (`clamp`), hero тайтла 28–52 px, компактный 24–36 px (мобильный 20–26 px);
кнопки 44–48 px. Мобильная сетка каталога: две колонки, поля 16 px.

Минимальный размер текста — 13 px; исключения только для микро-бейджей
и uppercase-меток в ограниченных по месту контролах (12 px) и подписей нижней
мобильной навигации (12 px). На практике 12 px также встречается в кнопке
«в библиотеку», языковом свитчере и подписях рельсы серий — это зафиксированное
отклонение, а не разрешение для нового мелкого текста. Общий масштаб типографики
зафиксирован токенами `--fs-caption` (13) / `--fs-small` (14) / `--fs-body` (16) /
`--fs-lead` (18) / `--fs-title` (20) / `--fs-section` (24) в `frontend/app/theme.css`.
Основная колонка контента — 1440 px (`--content-width`); горизонтальные полки
используют дробное число колонок, чтобы следующий постер выглядывал на ~30 %
осознанно, а стрелки полки появляются только при наведении/фокусе блока
(токена `--rail-fit` в коде нет — описание полок выше и есть контракт).

## Ассеты v0.2

Векторный набор — отрисовка того же кота в ягодной шляпе и шафрановом плаще.
SVG состоят из контуров; встроенного растра нет. Это упрощённая адаптация исходной
иллюстрации для разных размеров, а не точная трассировка всех её штрихов.

| Файл в frontend | Назначение |
| --- | --- |
| `public/brand-mascot-v02.svg` | Полный маскот, масштабируемые контуры |
| `public/brand-mark-v02.svg` | Компактный знак в шапке, обе темы |
| `public/brand-lockup-v02.svg` | Знак и название Anicast; Manrope переведён в контуры |
| `public/favicon-16.svg` | Отдельно упрощённая ручная версия 16 px |
| `app/favicon.ico` | 16/32/48 px из векторных источников |
| `app/icon.png`, `app/apple-icon.png` | 192 и 180 px |
| `public/og-v02.svg`, `public/og-v02.png` | Social preview 1200×630; PNG подключён в metadata |

Оригинальные растровые ассеты v0.1 сохранены для истории и страницы 404.
Цвета новых SVG заданы явно по таблице брендбука. Растровые иконки и OG
рендерятся из SVG; надписи OG не зависят от наличия шрифта у получателя.

Знак в шапке/подвале прозрачен: белая прямоугольная подложка CSS удалена.

Шапка на 768–1439 px имеет две строки (см. выше). На телефоне остаются компактная шапка и нижняя навигация; поле поиска
открывается в пределах viewport. Отступы якорей используют фактическую высоту
шапки. Мобильный hero тайтла располагает небольшой постер рядом с названием,
а основные действия — следующей полной строкой. Выбор озвучки имеет высоту
не менее 44 px и основной цвет текста в обеих темах.

Админка использует копию того же SVG в `backend/common/static/anicast/brand-mark.svg`;
при обновлении знака синхронизировать оба файла. Её палитра и theme script находятся
рядом в `admin.css`/`theme.js`. Они загружаются через Django staticfiles и общий
ключ `anicast-theme`; inline CSS блокируется production CSP.

## Проверка

`npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.
`npm run test:e2e` после build проверяет общий каркас на desktop/tablet/mobile.
В браузере: два режима, перезагрузка, независимость от ОС, клавиатура, mobile/desktop,
каталог, тайтл, вход, 404. Сравнивать реальный контент, не переносить демоданные PDF.
