# Социальные профили AniCast

## Первый публичный контур

Социальная идентичность строится вокруг opt-in профиля по адресу `/users/<public_id>`. Новый и существующий аккаунт закрыт по умолчанию. Пользователь сам задаёт имя, bio и включает публичность в `/settings`.

Публичная страница содержит только:

- имя в сообществе и bio;
- количество и карточки явно публичных коллекций;
- количество и последние одобренные модерацией рецензии.

Email, Telegram identity, история просмотров, библиотечные статусы, заметки, приватные коллекции, неподтверждённые рецензии и индивидуальные оценки не входят в публичный API. Закрытый или отключённый профиль отвечает `404`; ответы отправляются с `Cache-Control: no-store`, поэтому отключение публичности применяется сразу.

## Связи в интерфейсе

- Автор одобренной рецензии становится ссылкой только при включённом публичном профиле.
- Владелец публичной коллекции становится ссылкой при том же условии.
- `public_id` — стабильный UUID; внутренний числовой user id и email в URL не используются.

## API

- `GET /api/v1/public/users/<public_id>/` — публичная витрина или `404`.
- `GET /api/v1/account/profile/` — настройки владельца, нужна сессия.
- `PUT /api/v1/account/profile/` — изменение имени, bio и opt-in; нужна сессия и CSRF.

## Следующие социальные слои

Подписки, персональная лента и реакции должны опираться только на публичные профили. Перед их запуском нужны отдельные решения по блокировкам, жалобам, rate limits, удалению связей при закрытии профиля и модерации пользовательского контента. Историю просмотра нельзя превращать в публичную активность без отдельного явного согласия.
