# Социальные профили AniCast

## Первый публичный контур

Социальная идентичность строится вокруг opt-in профиля по адресу `/users/<public_id>`. Новый и существующий аккаунт закрыт по умолчанию. Пользователь сам задаёт имя, bio и включает публичность в `/settings`.

Публичная страница содержит только:

- имя в сообществе и bio;
- число подписчиков без раскрытия их списка;
- количество и карточки явно публичных коллекций;
- количество и последние одобренные модерацией рецензии.

Email, Telegram identity, история просмотров, библиотечные статусы, заметки, приватные коллекции, неподтверждённые рецензии и индивидуальные оценки не входят в публичный API. Закрытый или отключённый профиль отвечает `404`; ответы отправляются с `Cache-Control: no-store`, поэтому отключение публичности применяется сразу.

## Связи в интерфейсе

- Автор одобренной рецензии становится ссылкой только при включённом публичном профиле.
- Владелец публичной коллекции становится ссылкой при том же условии.
- `public_id` — стабильный UUID; внутренний числовой user id и email в URL не используются.
- Авторизованный пользователь может подписаться на открытый профиль и отписаться от него. Подписка на себя и закрытый профиль запрещена.
- Вкладка «Мои подписки» объединяет только одобренные рецензии и явно публичные коллекции открытых профилей. История просмотра, библиотека, заметки и оценки в ленту не попадают.
- Список подписчиков не публикуется. При закрытии профиля все входящие подписки удаляются, поэтому после повторного открытия прежняя аудитория автоматически не восстанавливается.

## API

- `GET /api/v1/public/users/<public_id>/` — публичная витрина или `404`.
- `GET /api/v1/account/profile/` — настройки владельца, нужна сессия.
- `PUT /api/v1/account/profile/` — изменение имени, bio и opt-in; нужна сессия и CSRF.
- `GET /api/v1/community/follows/<public_id>/` — состояние подписки и агрегированное число подписчиков; нужна сессия.
- `PUT /api/v1/community/follows/<public_id>/` — подписаться; нужны сессия и CSRF, лимит 60 изменений в час.
- `DELETE /api/v1/community/follows/<public_id>/` — отписаться; нужны сессия и CSRF, тот же лимит.
- `GET /api/v1/community/feed/` — персональная лента подписок; нужна сессия.

Персональные ответы подписок и ленты отправляются с `Cache-Control: no-store, private`.

## Следующие социальные слои

Следующий этап — блокировки пользователей, жалобы и реакции. Они должны опираться только на публичные профили и существующую модерацию. Историю просмотра нельзя превращать в публичную активность без отдельного явного согласия.
