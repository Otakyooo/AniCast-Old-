# Anicast: текущее состояние

Обновлено 09.09.2026. История прежних изменений сохранена в
[архиве](archive/IMPLEMENTATION_STATUS-2026-09-07.md); она не является актуальным runbook.

## Система

Next.js 15 / React 19 на VPS; Django 5.2 / DRF, PostgreSQL 17, Redis 7 и Celery
на MainServer. Публичный вход через Caddy; связь серверов через AmneziaWG.
Каталог, история, библиотека, коллекции, профили, поиск, уведомления и
воспроизведение через разрешённые источники уже реализованы.

## Релиз 08.09.2026

- Тёмная, светлая и системная темы по брендбуку; Manrope; новый маскот в шапке и favicon.
- Тема сохраняется и применяется до отображения страницы; русские и английские подписи.
- Выделенные Celery workers для уведомлений и длительных задач, concurrency 1.
- Frontend запускается пользователем node с лимитом памяти и постоянным кешем изображений.
- Скрипты релиза используют реальные Compose project names и проверяют наличие
  исходного манифеста отката; проверка Django при деплое останавливается на WARNING.
- Проектные skills и `AGENTS.md`, индекс документации, аудит и архитектурное решение.

Результаты проверок и факт выкладки фиксируются в [RELEASE-2026-09-08.md](RELEASE-2026-09-08.md).
Оставшиеся проблемы перечислены в [аудите](SYSTEM_AUDIT-2026-09-08.md).

## Этап 2: Redis

Необязательный cache выделен в отдельный ограниченный Redis на MainServer.
Throttles, locks и cursors сохраняются в прежнем noeviction-инстансе с очередями.
[Решение](architecture/002-redis-isolation.md), [проверки и статус выкладки](RELEASE-2026-09-08-redis.md).

## Этап 3: firewall VPS

Включён Anicast nftables firewall с boot unit; сохранены SSH, AWG, сайт,
relay, monitoring и egress MainServer. Docker DNAT контролируется отдельно
от INPUT. [Результаты и ограничения](RELEASE-2026-09-09-firewall.md).
