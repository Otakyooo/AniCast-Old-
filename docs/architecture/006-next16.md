# ADR 006: Next 16 без увеличения production-топологии

Дата: 09.09.2026. Решение принято для перехода с Maintenance LTS Next 15.

Next 16.3.4 / React 19.2.8 сохраняют App Router, SSR, Django API и image cache.
Сборщик — стандартный Turbopack; Node 22 Alpine и builder heap 768 MiB остаются.
Сборки и браузерные проверки выполняются на рабочей станции/CI, не на слабом VPS.
Новые сервисы, concurrency и RAM лимиты не добавляются.

`middleware.ts` переименован в `proxy.ts`, export — `proxy`. Это Node runtime,
а не прежний Edge runtime. Контракт защиты сохраняется: новый nonce для каждого
HTML, перезапись входящих nonce/CSP headers, private/no-store. Async request APIs
уже использовались. Cache Components и React Compiler отдельно не включаются.
WebP quality 92, разрешённый media origin и persistent image cache сохраняются;
доступ optimizer к произвольным локальным IP не включается.

ESLint переведён на native flat config. Новые компоненты получают весь gate.
Для 12 перечисленных старых loaders/player/session компонентов
`react-hooks/set-state-in-effect` временно остаётся warning: 18 диагностик.
Это видимый долг оптимизации, а не подтверждённая runtime-ошибка; переработка
состояния требует сценарных тестов плеера/аккаунта и отдельного изменения.
Остальные ошибки lint блокируют CI, npm audit по-прежнему блокирует high/critical.

CI дополнен Chromium-проверками общего каркаса на 1440×900, 820×1180, 390×844:
две явные темы, legacy system → dark, blocked storage, cross-tab persistence,
контраст навигации, прозрачный знак, nonce/no-store. API анонимного пользователя
подменён fixture; это не E2E реального входа/плеера.

Откат — предыдущие CI images и immutable env согласно [deployment](../operations/DEPLOYMENT.md).
Миграций схемы БД нет. В админке CSS вынесен в staticfiles, поскольку inline styles
блокируются CSP; политика безопасности не ослабляется ради оформления.

[Официальная миграция](https://nextjs.org/docs/app/guides/upgrading/version-16).
Версионные материалы после `npm ci`: `frontend/node_modules/next/dist/docs/`.
