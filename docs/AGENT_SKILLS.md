# Проектные skills Anicast

Точка входа для агентов — корневой `AGENTS.md`. Проектные инструкции находятся
в `.agents/skills/`, чтобы они версионировались вместе с кодом и документацией.

| Skill | Когда применять | Источники |
| --- | --- | --- |
| `anicast-ui` | Компоненты, страницы, темы, UI-проверка | `BRAND_UI_TECH_SPEC.md`, `FRONTEND_DESIGN_RULES.md` |
| `anicast-ops` | Runtime-аудит, Compose, релиз, диагностика и откат | `OPERATIONS.md`, последний `RELEASE-*.md`, ADR |

Оба skill-файла проверены штатным `quick_validate.py`. Это проверка структуры,
а не доказательство поведения всех будущих агентов. Установка глобальных
расширений или изменение личных настроек агента для работы с репозиторием не нужны.

`.cursor/rules/anicast-ui.mdc` уже ссылается на те же документы. Старые общие
материалы `.claude/skills/*.md` сохранены; они не являются источником production
адресов, палитры или текущей архитектуры. При расхождении использовать текущую
задачу пользователя и проектные документы. Не копировать секреты в skills.

Изменение workflow сопровождается обновлением соответствующего skill, а не
созданием нового общего «обязательного процесса» для каждой задачи.
