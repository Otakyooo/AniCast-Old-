## Изменения

Убраны 18 `react-hooks/set-state-in-effect` предупреждений из 12 компонентов
и исключение ESLint для них. Состояние тайтла, запроса библиотеки и player session
сбрасывается через ключ компонента; выбор озвучки/диапазона и прогресс привязаны
к текущей серии/источнику. Запоздавший ответ не возвращает прошлую серию или запрос.
Метки завершённых серий переживают смену озвучки и загрузку истории.

Сценарный тест выявил дополнительную гонку: устаревший ответ POST об открытии
серии мог прийти после успешного PATCH о завершении и убрать подтверждение с экрана.
Завершение внутри player session теперь монотонно; тест намеренно задерживает
ответ открытия до сохранения завершения и проверяет UI после его доставки.

Идентичность профиля подтверждается API до показа личных данных, язык берётся
из серверного i18n-контекста. Расписание использует минутный внешний clock snapshot
с отдельным SSR snapshot; первый клиентский кадр совпадает с серверным.
Поиск сбрасывает выбор при изменении запроса, но сохраняет результат при добавлении
пробела: одинаковый нормализованный запрос не должен зависать в загрузке.

Сценарии обнаружили цикл Next slash removal → Django APPEND_SLASH в запасном
Next API proxy. API rewrite теперь сохраняет слеши Django; poster file route
остаётся без завершающего слеша. Канонизация обычных страниц сохранена в Node proxy.
Production Caddy направляет API прямо в Django, поэтому этот цикл относился к
пути через Next, которым пользуется также тестовый стенд.

## Проверки и границы

Браузерный стенд запускает production Next build и реальный Django в CI. Каждый
запуск создаёт новую SQLite DB с искусственными пользователями/тайтлом. Проверяются
вход, неверный пароль, CSRF, выход и потеря cookie; восстановление/сохранение позиции,
завершение серии, повтор источника, смена озвучки и серии, запоздавший поиск.

Подписанный resolver проверяется настоящим запросом без автоматического follow;
только terminal video document подменён. Playwright не перехватывает последующий
запрос HTTP redirect chain, поэтому fixture после проверки 302 делает отдельную
навигацию iframe. Origin и source-window сообщений остаются реальными браузерными
границами. Внешняя доставка видео и реальный PostgreSQL concurrency этим не доказаны.
SQLite fixture использует IMMEDIATE transactions: у SQLite нет SELECT FOR UPDATE,
а deferred read→write upgrade при одновременных событиях иначе даёт database locked.
Email — in-memory, workers отсутствуют, повышенные test throttle rates остаются
в процессе fixture. Production данные и пользовательские учётные записи не используются.

Локально прошли 73 unit tests, lint без warnings, typecheck, production build,
seed-check через Django Client, actionlint и проверка ссылок документации.

VPS deploy/verify и MainServer verify прошли. Backend, workers, БД и Redis не
пересоздавались; CPU/RAM limits и concurrency сохранены. Приватный rollback snapshot:
`/root/anicast-react-38e63b7`; immutable runtime env остался прежним. Образ rollback
сохранён в previous manifest. Повторная браузерная проверка production прошла
на четырёх ширинах в обеих темах: нет overflow/перекрытия ссылок, voice targets 44 px,
мобильный поиск и Escape/focus работают, обычный trailing-slash URL даёт канонический
308 без цикла. Главная и titles API — 200; `/internal/metrics` — 404.
