# Страницы каталога, расписания и личных разделов — 09.09.2026

## Область и исходные находки

Цель этапа: закончить основные действия страниц без новых сервисов или увеличения
лимитов слабого VPS. Текущий сайт осмотрен во встроенном браузере; снимки этого
этапа сохранены локально в `artifacts/tab-pages/` (не входят в Git).

1. `before-catalog.jpg`: выборка «Выходит» содержит один тайтл. Кнопка случайного
   выбора обещала тайтл, но код открывал случайную страницу и терял фильтры.
   Поле поиска не растягивалось из-за неверного CSS selector после добавления chips.
2. `before-schedule.jpg`: на пустой неделе не были видны ни даты, ни дни недели.
   Проверка кода также выявила превращение ошибки API в сообщение об отсутствии
   релизов; аналогичная проблема была в каталоге.
3. `before-history.jpg`: история ограничивалась первыми 20 записями. В реализации
   не было навигации и повторной загрузки после ошибки. Личные данные при осмотре
   не менялись; для тестов используются только синтетические записи.
4. Стили библиотеки перекрывали выделение выбранного фильтра и представления.
   После ошибки запроса пользователь оставался без действия восстановления.

## Изменения

- Случайный выбор запрашивает одну запись из всей отфильтрованной выборки и
  открывает её страницу. Есть pending, защита от повторного клика, abort при уходе
  и ошибка с возможностью повторить действие.
- Каталог сохраняет фильтры при сбое API; 404 пагинации отделён от недоступности.
  Удаление chip синхронизирует поля формы. Исправлены ширина поиска, пустая строка
  chips, touch targets и цвет hover в светлой теме.
- Расписание сохраняет календарь и диапазон дат на пустой неделе и при сбое.
  Ошибка не выдаётся за нулевое число релизов. Панель доступна с клавиатуры.
- История получила URL-пагинацию, retry, возврат с исчезнувшей страницы и переход
  в каталог из пустого состояния.
- В библиотеке восстановлено видимое выделение, добавлены retry и восстановление
  пагинации; ссылки страниц сохраняют status и favorite вместе.
- Мобильные снимки выявили текст профиля поверх затемнённого баннера в светлой
  теме. Теперь баннер перекрывает только аватар с непрозрачной подложкой, а имя и
  описание остаются на поверхности контента; положение проверяется в E2E.
- Все новые сообщения переведены на русский и английский.

## Проверки и выпуск

Локально: lint без ошибок/предупреждений, typecheck, 73 unit tests, production
build и seed-check изолированной Django fixture прошли. Браузерные сценарии
расширены проверками фильтров, случайного выбора, серверных ошибок, пустого
расписания, пагинации истории и retry библиотеки. CI сохраняет снимки четырёх
viewport в обеих темах. Статус полного CI, выпуска и production-проверки будет
зафиксирован после их завершения.

## Границы

Это средний этап для четырёх страниц, а не аудит всех функций сайта. Франшизы,
публичные коллекции, сообщество и редактор коллекций требуют отдельного прохода.
Снимки и Chromium-сценарии не подтверждают полную WCAG-совместимость, работу
screen reader или Safari/Firefox. Нагрузочные лимиты и архитектура не менялись.
