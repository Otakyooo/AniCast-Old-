# Карточка тайтла, метаданные и плеер

## Названия и поиск

`TitleSerializer.localized_names` отдаёт доступные официальные варианты в стабильном формате:

```json
{"ru": "Большой куш", "en": "One Piece", "ja": "ONE PIECE"}
```

Пустой язык не включается. Одинаковые официальные написания не объединяются: интерфейс сохраняет языковую подпись. Поле `name` остаётся локализованным согласно языку запроса для обратной совместимости. Каталог и глобальный поиск ищут по `Title.name`, `Title.original_name` и всем `TitleTranslation.name`.

## Авторы и персонажи

Основные авторы (режиссёр, сценарист, продюсер) показываются в обзоре тайтла; полный список остаётся во вкладке «Персонажи и авторы». Источник авторов — `material_data` Kodik, синхронизация выполняется существующей задачей `sync_kodik_library`.

Причиной неполного состава было историческое ограничение импорта `--characters=8`. `sync_title_characters` получает весь `characterRoles` одним GraphQL-запросом Shikimori, создаёт недостающие RU/EN-переводы и идемпотентно связывает роли с тайтлом. Тяжёлые карточки выдаются по 60 персонажей через `characters_page`; общее число находится в `characters_count`.

Ручной запуск:

```bash
python manage.py sync_title_characters 21-one-piece --apply
python manage.py sync_title_characters --all --apply
```

Celery Beat запускает `catalog.tasks.sync_character_library` каждый час порциями по 5 тайтлов.

## Названия и даты эпизодов

Первичный источник — Jikan/MAL. При недоступности Jikan используется `api.ani.zip`, который отдаёт TVDB-сопоставление, дату и RU/EN/JA-названия эпизода. Резервный источник:

- не перезаписывает редакторское название;
- не перезаписывает точное `air_at` от Kodik;
- заполняет только отсутствующие `air_date` и переводы;
- ограничен таймаутом 30 секунд и размером ответа 20 МБ.

Очередь выбирает эпизоды без названия **или** без даты, поэтому ранее пропущенные записи постепенно попадают в расписание после появления подтверждённых дат.

## Макет просмотра

AniCast владеет выбором серии и варианта озвучки/субтитров. Kodik остаётся поставщиком видео, но не создаёт второй конкурирующий уровень навигации внутри iframe. На desktop серии постоянно доступны рядом с плеером; на узком экране тот же набор открывается компактной мобильной панелью. Календарной сетки и отдельного маршрута просмотра нет.

Каждый вариант показывает реальное покрытие (`1–130`, `1–1122, кроме 269, 278`), а не долю запусков. Переключение варианта сохраняет текущую серию, если она доступна; недоступность не приводит к молчаливому переходу на другую серию.

### Стабильная идентификация варианта

Для источников Kodik API отдаёт `provider_variant_id` — строковый `translation_id` провайдера, одинаковый у всех серий одной озвучки или набора субтитров. Публичный `selection_key` остаётся непрозрачным, но строится из provider, типа источника и этого стабильного идентификатора, а не из отображаемого названия. Переименование студии в Kodik поэтому не ломает сохранённый выбор и новые `?voice=` URL.

Группа в `/watch-navigation/` дополнительно содержит `legacy_key`, рассчитанный по прежней схеме provider + тип + текущее название. Frontend принимает как новый `key`, так и `legacy_key`; при распознавании старой ссылки заменяет query-параметр на стабильный `key`. `SourceSerializer` отдаёт `provider_variant_id` и тот же `selection_key`, чтобы выбранная группа однозначно сопоставлялась с источником текущего эпизода.

Для источников без подтверждённого стабильного идентификатора `provider_variant_id` равен `null`, а `selection_key` сохраняет прежнюю схему. Название не используется как Kodik identity и не раскрывает внутренний content id провайдера.

### Параметры iframe Kodik

`sync_kodik` сохраняет текущую episode-specific ссылку источника с `hide_selectors=true`. Существующие безопасные query-параметры сохраняются, ранее переданный `hide_selectors` заменяется, а `only_episode` удаляется. Режим `only_episode` не применяется: AniCast переключает конкретные серии своими per-source ссылками, не отключая совместимый serial runtime Kodik.

Параметр хранится непосредственно в URL источника; `Provider.playback_config` остаётся пустым. Это сохраняет совместимость с предыдущей версией iframe adapter и позволяет откатить backend без остановки playback. После выкладки требуется целевой либо полный `sync_kodik --apply`, чтобы обновить уже существующие Source.

Счётчик увеличивается только после успешной проверки короткоживущего playback-токена и перенаправления к провайдеру. Абсолютное число запусков наружу не отдаётся — API возвращает только `popularity_percent` для порядка вариантов; интерфейс не выдаёт эту метрику за покрытие озвучки. Навигация кэшируется на 60 секунд, поэтому новый порядок может появиться с небольшой задержкой. Пользовательские блоки «Доступно серий» и «Все источники и диагностика» из страницы просмотра удалены.

URL источника никогда не входит в навигационный payload: iframe по-прежнему получает короткоживущую подписанную ссылку через playback resolver.

## Настройки сайта в Kodik

В кабинете Kodik сайт настроен для `*.anicast.online`, включая поддомены. Данные доступа и внутренний идентификатор сайта в репозитории, документации и логах не сохраняются.

Глобальная доступность встроенных селекторов, автосохранение и автоматическое переключение в кабинете оставлены без изменений ради безопасного rollback. В актуальном интерфейсе внутренние селекторы скрываются только параметром конкретного Source URL. Брендовые цвета AniCast применены на стороне Kodik, поэтому резервный интерфейс плеера не выбивается из визуальной системы сайта.

## Проверка после выкладки

1. `/api/v1/titles/21-one-piece/` содержит `localized_names`, `characters_count`, `credits`.
2. Поиск RU/EN/JP-вариантов возвращает один и тот же slug.
3. `/titles/21-one-piece?tab=characters&characters_page=2` открывает следующую страницу состава.
4. `/watch-navigation/` отдаёт одинаковый `key` для Kodik-источников с одним `provider_variant_id`, даже если отображаемое название изменилось, и содержит рабочий `legacy_key`.
5. Playback resolver перенаправляет на episode-specific URL с `hide_selectors=true`, без `only_episode` и без раскрытия URL в навигационном payload.
6. `/titles/21-one-piece?episode=1` переключает серии и озвучки на карточке тайтла; `/titles/21-one-piece/watch` отвечает 404.
7. Количество `Episode(air_date IS NULL)` уменьшается после фоновых проходов; точные `air_at` не меняются.
